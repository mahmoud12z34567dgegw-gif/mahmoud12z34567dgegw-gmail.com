# أكاديمية أهل القرآن — Android بدون دومين (تجربة محلية)

هذا مشروع Android مستقل عن أي رابط موقع. افتح التطبيق وسيعرض واجهة الأكاديمية المعبأة في `app/src/main/assets/` دون السؤال عن دومين أو الاعتماد على استضافة.

**الحدود بوضوح:**
- نسخة تجريبية **على جهاز واحد**، وليست نظام تسجيل دخول آمن لعدة أشخاص. زر التبديل بين المدير والمعلم والطالب هو معاينة أدوار فقط.
- يمكنك إضافة أسماء تجريبية ومقررات وجدول حلقات وواجبات نصية، ثم تجربة تسليم الطالب وتصحيح المعلم على **الجهاز نفسه**. التغييرات تحفظ في التخزين الخاص بالتطبيق (SharedPreferences)، وقد تضيع عند إزالة التطبيق أو مسح بياناته.
- لا يوجد شات حي، أو مكالمات فيديو ومشاركة شاشة، أو رفع صوتيات ومزامنة بين الأجهزة: هذه وظائف تحتاج خدمة سحابية وهوية المستخدمين والاتصال الآمن. لا يلزم شراء دومين خاص: يمكن لاحقًا استخدام عنوان مجاني تلقائي من الاستضافة (`*.pages.dev` أو `*.workers.dev` بحسب الخدمة والإعداد).
- زر المصحف يفتح مصدر قراءة خارجي عبر المتصفح عند وجود الإنترنت.
- لا تدخل بيانات طلاب حقيقية في النسخة التجريبية.

## إنشاء APK
هذه الحزمة تحتوي **مشروع Android، لا ملف APK مُجمّعًا**. السبب: Android SDK غير متوفر في بيئة تجهيز الملف. على Windows: ثبت Android Studio وAndroid SDK Platform 35، ثم اضغط `BUILD_APK_WINDOWS.bat` داخل المجلد. سيُنشئ عند النجاح `AhlAlQuran-debug.apk`، وهو APK للاختبار والتجربة، وليس إصدارًا موقّعًا للتوزيع العام. راجع `BUILD_GUIDE_AR.txt`.

يمكن أيضًا البناء من GitHub Actions عن طريق ملف `.github/workflows/build-apk.yml` إذا وضعت مجلد المشروع في مستودع GitHub خاص، ثم استخدمت `Run workflow` وحمّلت artifact.

## تحققنا منه
- فحص صياغة JS باستخدام `node --check`.
- التحقق من وجود الأصول المرجعية وملف Manifest وملفات بناء Gradle.
- تعذرت المعاينة الآلية داخل متصفح الاختبار بسبب سياسة بيئته، وتعذر تجميع APK بسبب غياب Android SDK؛ ينبغي اختبار التطبيق على جهاز Android بعد البناء.

ملفات المشروع الخاصة: `app/src/main/assets/{index.html,style.css,app.js,academy-logo.jpg}` و`MainActivity.java`.
