# أكاديمية أهل القرآن — Android Smart v1.3 (نسخة محلية تجريبية)

النسخة دي تطوير فعلي لمشروع Android WebView السابق مع الاحتفاظ بـ applicationId: `com.ahlquran.academy`.

## الجديد
- تسجيل دخول تجريبي ببريد مختلف وكلمة مرور لكل دور، وإخفاء تبديل الأدوار المفتوح من الواجهة.
- المدير يضيف حسابات تجريبية للمعلمين والطلاب ببريد محلي وكلمة مرور، ويعيد تعيين كلمات المرور للحسابات المضافة.
- شاشة دخول جديدة ذات هوية إسلامية مع رسومات SVG محلية وشعار الأكاديمية، Gradients وانتقالات حركة، وبطاقات تعليمية مصوّرة.
- مظهر أخضر/بنفسجي/أزرق/ذهبي، مع وضع داكن، وقائمة جانبية للكمبيوتر وسفلية للموبايل، وبحث محلي وتنبيهات من بيانات الحلقات والواجبات.
- تقويم أسبوعي قابل للتصفح، وعينات حلقات للتجربة، ومنع تداخل موعدَي معلم واحد.
- الحفاظ على المقررات والواجبات النصية والتسليم والتصحيح وخطط الحفظ والحضور والتصدير/الاستيراد المحلي.
- فصل حلقات وواجبات المعلمين داخل بيانات الجهاز الواحد.

## الحسابات التجريبية
- مدير: `admin@ahlquran.test` / `AdminDemo#2026`
- معلم: `teacher@ahlquran.test` / `TeacherDemo#2026`
- طالب: `student@ahlquran.test` / `StudentDemo#2026`
زر كل حساب على شاشة الدخول يملأ بياناته تلقائيًا. هذه عناوين هوية تجريبية داخل التطبيق وليست صناديق بريد حقيقية، ولم تُنشأ على أي مزود بريد.

## مهم: حدود النسخة
هذا تطبيق محلي على جهاز واحد **وليس** منصة آمنة متعددة المستخدمين. واجهة كلمة المرور محلية ويمكن لمالك الجهاز أو من لديه وصول إلى ملفات التطبيق أو الكود تجاوزها؛ لا تصلح للتعامل مع بيانات أطفال حقيقية. قيم SHA-256 مع ملح فردي للحسابات الجديدة، لكنها ليست بنية مصادقة إنتاجية؛ ذلك يتطلب خادمًا آمنًا وسياسات وصلاحيات وجلسات فعلية. لا بريد إرسال/استقبال، ولا شات حقيقي بين أجهزة مختلفة، ولا اجتماع فيديو أو مشاركة شاشة بين المستخدمين. المصحف يفتح رابطًا خارجيًا ويتطلب إنترنت.

## البناء
- على GitHub: ارفع `app` وباقي الملفات بالمجلدات نفسها، احتفظ بمجلد `.github/workflows` وشغّل Build Android test APK من Actions.
- GitHub يخرج `app-debug.apk` داخل Artifacts وهو APK تجريبي موقّع بمفتاح Debug، وليس حزمة نشر رسمية.
- للأجهزة ذات الإصدار السابق: اختلاف توقيع Debug عبر تشغيلات مختلفة يمكن أن يمنع التحديث فوق النسخة القديمة. احتفظ بنسخة احتياطية JSON قبل التبديل، ولا تحذف بياناتك قبل حفظها. بعض النسخ القديمة قد لا تتوافق في نقل البيانات بين تطبيقين مختلفي التوقيع؛ يفضّل مفتاح توقيع Release ثابت بعد اكتمال تجربة المنتج.
- لا حاجة لدومين، ولا حاجة لـAndroid Studio إذا كانت عملية GitHub Actions متاحة وتعمل.
