# أكاديمية أهل القرآن — تحديث Android المحلي 1.2

هذا تطوير للنسخة المحلية السابقة المبنية على WebView. لا يتطلب دومينًا أو خادمًا، ويحتفظ بالبيانات الموجودة على نفس الجهاز عند التحديث إذا كان توقيع APK متوافقًا ولم تُمسح بيانات التطبيق.

## الجديد
- خطط حفظ ينشئها المعلم لطالب، الطالب يضع «أتممت المراجعة» والمعلم يعتمدها، وشريط تقدم.
- سجل حضور الطلاب لكل حلقة يحدده المعلم، ويشاهده الطالب من واجهته.
- منع تداخل الجلسات حسابيًا على أساس وقت البداية والمدة، وليس تطابق وقت البداية فقط.
- نسخ احتياطي JSON تصدير/استيراد عبر منتقي ملفات Android.
- SVG أيقونات وقائمة «المزيد» على الشاشات الصغيرة.
- تحديث ملف GitHub Actions إلى setup-android@v4 مع packages: platform-tools وفق الإصلاح السابق.

## مهم
هذه نسخة تجريبية محلية على جهاز واحد؛ تبديل الأدوار معاينة وليس نظام هوية آمن. لا شات مباشر ولا مكالمات عبر الإنترنت أو مزامنة بين الأجهزة. لا تدخل بيانات شخصية حقيقية.

## البناء
ارفع ملفات المشروع بنفس مساراتها إلى GitHub وشغّل Build Android test APK من Actions. لا يوجد ملف APK مبني مسبقًا بهذه الحزمة.
