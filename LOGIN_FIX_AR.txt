أكاديمية أهل القرآن — تصحيح تسجيل الدخول v1.3.1

السبب: كان الحدث العام للضغط يستخدم closest('[data-theme]')؛ وحيث إن BODY يحمل data-theme، كان كل ضغط يصل إلى BODY ويعاد رسم شاشة الدخول قبل أن تعمل أزرار الحسابات أو زر الدخول.

التعديل: closest('.theme-dot[data-theme]') بحيث يستجيب فقط لأزرار تغيير الثيم الحقيقية.

إذا أردت تعديل مشروع GitHub الموجود مباشرة بدون إعادة رفع المجلد:
1) افتح Code > app > src > main > assets > app.js > علامة القلم (Edit).
2) ابحث عن:
   e.target.closest('[data-theme]')
3) واستبدله بهذا فقط:
   e.target.closest('.theme-dot[data-theme]')
4) اضغط Commit changes.
5) Actions > أحدث تشغيل ناجح > Artifacts > AhlAlQuran-debug-APK.

بدل التعديل اليدوي يمكن استخدام ZIP المرفق؛ احرص على بقاء المسار app/src/main/assets/app.js وعدم إنشاء مجلد مزدوج app/app. حزمة المشروع الكامل تضم ملف workflow الذي نجح بالإصدار setup-android@v4.

تأكد من تحديث التطبيق بالنظر إلى 1.3.1 في شاشة الدخول. في النسخة التجريبية:
المدير admin@ahlquran.test / AdminDemo#2026
المعلم teacher@ahlquran.test / TeacherDemo#2026
الطالب student@ahlquran.test / StudentDemo#2026
اضغط زر الدور لملء البيانات تلقائيا ثم الدخول.

لا تزل التطبيق القديم إن كان عليه بيانات مهمة قبل أخذ نسخة احتياطية. وقد يتطلب اختلاف توقيع Debug إلغاء تثبيت النسخة السابقة بعد حفظ البيانات، ثم تثبيت الجديدة.
هذه نسخة محلية تجريبية وليست حسابات أو بريدًا حقيقيًا.
