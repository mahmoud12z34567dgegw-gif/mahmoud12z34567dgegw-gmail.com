طريقة إنشاء APK لأكاديمية أهل القرآن — من غير دومين
==================================================
هذا المشروع لا يطلب رابطًا عند التشغيل. يفتح نسخة محلية تجريبية من واجهات الأكاديمية.

1. نزّل Android Studio من https://developer.android.com/studio ثم ثبّته.
2. افتح Android Studio مرة واحدة وأكمل Setup Wizard وثبّت Android SDK Platform 35.
3. فك الضغط بالكامل، ثم شغّل BUILD_APK_WINDOWS.bat من داخل المجلد.
4. يحتاج البناء اتصال الإنترنت أول مرة لتنزيل Gradle وإضافات Android.
5. عند نجاح العملية ستجد AhlAlQuran-debug.apk في مجلد المشروع. انقله إلى هاتف Android وثبّته للاختبار، بعد مراجعة تحذير تثبيت التطبيقات من مصدر خارجي.

بديل: افتح المجلد من Android Studio ثم Build > Build Bundle(s) / APK(s) > Build APK(s).
بديل سحابي: ارفع مشروع المصدر إلى مستودع GitHub خاص واستخدم Actions > Build Android test APK > Run workflow ثم نزّل artifact.

تنبيه: هذا APK تجريبي بدون خادم؛ الاسم والمقررات والجدول والواجبات المحفوظة لا تتزامن بين الأجهزة. شات حقيقي ومكالمات حقيقية يستلزمان Backend مؤمنًا؛ عنوان الاستضافة المجاني يكفي ولا تحتاج شراء دومين مخصص.
إن أردت توزيعه رسميًا، أنشئ Release Signed APK/AAB بمفتاح توقيع خاص بك واحفظ المفتاح بأمان. لا توزع debug APK للإنتاج.
