طريقة تحديث تطبيق أكاديمية أهل القرآن إلى النسخة الذكية 1.3

1. نزّل AhlAlQuran-SMART-v1.3-GITHUB-UPDATE.zip وفك الضغط على الكمبيوتر.
2. افتح مشروع الأكاديمية الحالي على GitHub في تبويب Code، ثم Add file ثم Upload files.
3. افتح مجلد ZIP المفكوك واسحب مجلد app (بما فيه المجلدات والملفات داخله) إلى صفحة الرفع. لا ترفع ZIP نفسه.
4. راجع المسارات: يجب أن تكون app/build.gradle و app/src/main/assets/index.html و app/src/main/assets/app.js و app/src/main/assets/style.css وملفات الصور داخل app/src/main/assets مباشرة، وليست تحت مجلد إضافي باسم ZIP.
5. اضغط Commit changes. اترك مجلد .github/workflows الحالي الذي نجح معك كما هو؛ حزمة التحديث لا تستبدله.
6. اضغط Actions وافتح أحدث Build Android test APK. بعد العلامة الخضراء، انزل إلى Artifacts وحمّل AhlAlQuran-debug-APK، ثم فك الضغط وخذ app-debug.apk.
7. جرّب الحسابات الثلاثة المكتوبة في DEMO_ACCOUNTS.txt، واختبر التنقل والجدول.

ملحوظة: لو APK القديم مثبت وعليه بيانات، احتفظ به وخذ Export backup منه أولًا. قد لا ينجح التثبيت فوق القديم إذا تغيّر مفتاح التوقيع التجريبي بين عمليات GitHub. لا تحذف النسخة القديمة قبل التأكد من نسخة احتياطية قابلة للاستيراد.
هذه نسخة محلية تجريبية، وليست مصادقة إنترنت أو خدمة بريد أو شات مباشر.
