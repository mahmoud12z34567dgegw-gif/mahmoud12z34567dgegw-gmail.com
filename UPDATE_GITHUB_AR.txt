تحديث أكاديمية أهل القرآن إلى الإصدار المحلي 1.2

1) احتفظ بنسخة من APK القديم والبيانات إن كانت مهمة. الإصدار الجديد يحتفظ بنفس applicationId، لكن ملف APK التجريبي الجديد قد يختلف توقيعه بين بيئات بناء GitHub. إذا رفض Android التحديث، صدّر نسخة بيانات من داخل الإصدار الجديد في التحديثات المستقبلية؛ لا تمسح بيانات التطبيق القديم دون نسخة احتياطية.
2) استبدل محتويات مشروع GitHub بمحتويات هذا المجلد مع الحفاظ على المسارات الأصلية، بما فيها .github/workflows/build-apk.yml. لتجنب صعوبة رفع المجلدات المتداخلة على واجهة الويب، يمكنك تعديل الملفات الخمسة مباشرة عبر قلم GitHub: app/src/main/assets/index.html, app.js, style.css, app/src/main/java/com/ahlquran/academy/MainActivity.java, app/build.gradle بالإضافة إلى workflow. خيار أسهل لأصحاب الكمبيوتر هو GitHub Desktop أو git.
3) من Actions افتح Build Android test APK واستخدم Run workflow ثم حمّل الملف من Artifacts عند ظهور العلامة الخضراء.
4) للمشاهدة السريعة افتح ملف PREVIEW.html على Chrome من الكمبيوتر.

الجديد: خطط الحفظ ومتابعة اعتماد المعلم، حضور الحلقات، كشف تداخل المواعيد، نسخ احتياطي واستيراد محلي عبر منتقي ملفات Android، قائمة موبايل محسنة، وأيقونات موحدة.

النسخة تجريبية محلية على جهاز واحد، وليست مصادقة آمنة لمدير/معلم/طالب ولا شات أو فيديو بين الأجهزة، لذلك لا تُدخل بيانات طلاب حقيقية.
